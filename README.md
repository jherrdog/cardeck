# CARDECK

A commonplace book in the style of Ryan Holiday's notecard system: every idea on its own index card, filed by theme.

This repository holds only the app. The cards live in a separate private repository, as Markdown files, one card per file. Each device keeps a copy so cards open instantly and work offline.

Runs entirely in the browser. No server, no accounts beyond GitHub, nothing to pay for.

Fonts: Source Serif 4 and Caveat, both under the SIL Open Font License (see `fonts/LICENSE.txt`).
